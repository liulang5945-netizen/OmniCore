解释一下什么是递归
这是编程概念问题，直接回答即可。
递归是一种编程技巧，指函数调用自身。

**两个要素：**
1. 基准条件（base case）：停止递归的条件
2. 递归步骤（recursive step）：将问题分解为更小的子问题

**示例 - 阶乘：**
```python
def factorial(n):
    if n <= 1:  # 基准条件
        return 1
    return n * factorial(n - 1)  # 递归步骤
```

**注意事项：**
- 必须有基准条件，否则会无限递归
- 递归深度过大会导致栈溢出
- 某些场景下迭代更高效

帮我写一个快速排序算法
好的，这是一个 Python 实现的快速排序算法：

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

# 测试
arr = [3, 6, 8, 10, 1, 2, 1]
print(quicksort(arr))  # [1, 1, 2, 3, 6, 8, 10]
```

**算法原理：**
1. 选择一个基准元素（pivot）
2. 将数组分为三部分：小于、等于、大于基准
3. 递归排序左右两部分
4. 合并结果

**时间复杂度：**
- 平均：O(n log n)
- 最坏：O(n²)（当数组已排序时）

1. **监督学习** — 有标签数据训练

   - 聚类：将数据分组
   - 降维：减少特征数量

3. **强化学习** — 通过试错学习
   - 游戏 AI、机器人控制

- 线性回归、逻辑回归
